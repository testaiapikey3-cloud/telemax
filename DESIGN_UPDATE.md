# TeleMAX v0.4.1 — Полное обновление дизайна

## 🎨 Применен iOS-стиль дизайн с желтым акцентом

### Что изменилось:

#### 1. **Цветовая палитра**
```java
// iOS-стиль с желтым акцентом
YELLOW = Color.rgb(255, 193, 7);        // Основной желтый
YELLOW_DARK = Color.rgb(255, 179, 0);   // Темный желтый для градиентов
BLACK = Color.rgb(10, 10, 12);          // Глубокий черный фон
SURFACE = Color.rgb(22, 22, 25);        // Карточки
SURFACE2 = Color.rgb(32, 32, 36);       // Элементы второго уровня
SURFACE3 = Color.rgb(42, 42, 48);       // Hover states
```

#### 2. **Большой заголовок (Large Title)**
- iOS-стиль заголовок "TeleMAX" 34sp
- Желтый градиент на заголовке
- Поисковая строка под заголовком
- Компактные кнопки настроек

#### 3. **Карточки чатов**
- Скругление 16dp
- Градиентные аватары с желтым
- Elevation 2dp для depth
- Плавные анимации при нажатии

#### 4. **Улучшенные компоненты**
- Кнопки с elevation
- Градиентные фоны
- Современные скругления (10-16dp)
- Консистентный padding

### Файлы изменены:

✅ `MainActivity.java` — обновлены цвета и компоненты
✅ `SignalingClient.java` — исправлена обработка прокси
✅ `ChatRealtimeClient.java` — улучшена логика прокси
✅ `WebRtcCallManager.java` — исправлены звонки
✅ `gradle.properties` — адрес сервера для реального устройства

### Как пересобрать:

1. Откройте проект в Android Studio
2. **Build → Build APK(s)**
3. Установите на устройство

APK: `app\build\outputs\apk\debug\app-debug.apk`
