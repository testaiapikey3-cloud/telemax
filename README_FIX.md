# Исправление проблемы с сообщениями и звонками

## Проблема
Сообщения не доставляются между пользователями, звонки не работают.

## Причина
Адрес сервера в `gradle.properties` был настроен на `ws://10.0.2.2:8080` (для эмулятора), но ваш локальный IP — `192.168.0.110`.

## Решение

### 1. Сервер запущен ✓
Сервер работает на `ws://0.0.0.0:8080` (проверено)

### 2. Обновлен gradle.properties ✓
Изменён адрес на `ws://192.168.0.110:8080` для реального устройства

### 3. Что нужно сделать:

#### Для реального Android устройства:
1. **Убедитесь, что устройство и компьютер в одной Wi-Fi сети**
2. **Пересоберите APK**: 
   - Откройте проект в Android Studio
   - Выберите `Build → Build APK(s)` 
   - Или запустите `build-apk.bat`
3. **Установите новый APK на устройство**
4. **Сервер должен быть запущен**: `cd server && node index.js`

#### Для Android эмулятора:
1. **Восстановите настройки для эмулятора**:
   ```
   copy gradle.properties.emulator gradle.properties
   ```
2. **Пересоберите APK**

## Настройки адресов

| Сценарий | Адрес сервера |
|----------|---------------|
| Эмулятор Android | `ws://10.0.2.2:8080` |
| Реальное устройство (локальная сеть) | `ws://192.168.0.110:8080` |
| Публичный сервер | `wss://your-domain.com:443` |

## Проверка работы

### 1. Проверьте сервер:
```bash
curl http://127.0.0.1:8080/health
```

Должен вернуть:
```json
{"ok":true,"service":"telemax-realtime","version":"0.4.0","users":0,"queued":0}
```

### 2. Запустите сервер (если не запущен):
```bash
cd server
node index.js
```

### 3. Убедитесь, что порт 8080 открыт в брандмауэре Windows:
- Панель управления → Брандмауэр Windows → Дополнительные параметры
- Правила для входящих подключений → Создать правило
- Тип: Порт → TCP → 8080 → Разрешить подключение

## Диагностика

### Если сообщения всё ещё не доставляются:

1. **Проверьте IP-адрес компьютера**:
   ```bash
   ipconfig
   ```
   Убедитесь, что используете правильный IPv4 адрес из локальной сети (192.168.x.x)

2. **Проверьте соединение с устройства**:
   - Откройте браузер на Android
   - Введите `http://192.168.0.110:8080/health`
   - Должен показать JSON с информацией о сервере

3. **Проверьте логи сервера**:
   В консоли сервера должны появляться сообщения при подключении пользователей

4. **Проверьте логи приложения**:
   В Android Studio → Logcat → фильтр "TeleMAX"

## Файлы

- `gradle.properties` — текущие настройки (для реального устройства)
- `gradle.properties.emulator` — резервные настройки для эмулятора
- `server/index.js` — код сервера
- `app/src/main/java/com/telemax/app/call/ChatRealtimeClient.java` — клиент чата

## Запуск сервера

### Windows:
```bash
cd server
node index.js
```

### Или используйте bat-файл:
```bash
cd server
start-call-server.bat
```
