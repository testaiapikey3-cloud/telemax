# TeleMAX Web — мессенджер (сайт: HTML + CSS + JS)

Полноценная веб-версия TeleMAX. Вместо APK — сайт из множества отдельных файлов
плюс маленький сервер на Node.js для реального обмена сообщениями между людьми.

**Bluetooth убран полностью** — в веб-версии он не нужен и не поддерживается.

---

## 🚀 Быстрый запуск

1. Установите [Node.js](https://nodejs.org) (если ещё не установлен).
2. Откройте терминал в папке `website` и выполните **один раз** `npm link` —
   появится команда `telemax`, она работает из любой папки:

   ```
   telemax start      # запустить сервер → http://localhost:8080
   telemax tunnel     # публичная ссылка в интернет (в отдельном окне)
   telemax open       # открыть сайт в браузере
   telemax help       # справка
   ```

   Без `npm link` — то же самое через npm (в папке `website`):

   ```
   npm start          # сервер
   npm run tunnel     # публичный туннель
   ```

3. Откройте сайт сразу на двух устройствах/вкладках — зарегистрируйте двух
   пользователей и общайтесь в реальном времени.

> Остановить сервер: `Ctrl+C` в том же окне терминала.
> Запасной «мышиный» способ для Windows: `START.bat` / `TUNNEL.bat`.

Без сервера сайт тоже работает — в **офлайн-режиме** (всё хранится в браузере),
но сообщения между людьми будут доставляться только при запущенном сервере.

## 🌐 Что умеет

### 🔔 Уведомления (звук + вибрация)
- ✅ Системные уведомления о сообщениях и звонках — со **звуком и вибрацией**
- ✅ **Push-уведомления**: приходят, даже когда сайт закрыт или телефон в спящем режиме
  (кнопка «Включить» спросит один раз после входа; Настройки → «Уведомления» → тест)
- ✅ Играют даже во **скрытой вкладке** (Web Audio-«дзынь» и системный звук push)
- ✅ **Звонки**: рингтон с вибрацией; если человек не в сети — ему уходит push «Входящий
  звонок», и вызов дозвонит, если он зайдёт в течение 45 секунд
- ✅ Тихие часы (23:00–08:00), тумблеры звука и вибрации
- ⚙️ Техника: service worker (`sw.js`) + Web Push (VAPID, aes128gcm) + PWA-манифест
  и иконки. На Android/ПК достаточно разрешения; на iPhone (iOS 16.4+) — добавьте
  сайт на экран «Домой» («Поделиться» → «На экран Домой»)
- ⚙️ Сервер: `server/push.js` — своя реализация Web Push на встроенном `crypto`,
  без дополнительных npm-модулей

### Сообщения и медиа
- ✅ Текстовые сообщения (1-на-1, группы, каналы)
- ✅ **Фото** — отправка, просмотр в полноэкранном режиме «N из M» с эскизами
- ✅ **Видео** — отправка и воспроизведение прямо в чате
- ✅ **Файлы** — любые файлы, скачивание в один клик, показ размера
- ✅ **Голосовые** — запись с микрофона прямо из браузера (MediaRecorder);
  во время записи кнопки **«Отправить»** и «Отмена»
- ✅ **Опросы с голосованием** — вопрос + до 10 вариантов, живые проценты,
  голос виден всем участникам чата (1-на-1 и группы)
- ✅ Ответы на сообщения, удаление, статусы ✓ / ✓✓ / ✓✓ синим (прочитано)
- ✅ «Печатает…» и онлайн-статусы («в сети», «был(а) в 14:32»)
- ✅ Боты: **TeleMAX Bot** (/start, /help, /id — профиль и роль), **BotRast**
  (/newbot — создаёт бота и **выдаёт токен**, /mybots, /token),
  **TeleMany** (/addbot ТОКЕН, описание, /newpost, /subscribers, /lastpost);
  боты отвечают на текстовые команды (на медиа не спамят)
- ✅ Группы и каналы (создание, участники, владелец)
- ✅ Звонки WebRTC — аудио и видео, история звонков (Все / Пропущенные /
  Входящие / Исходящие)

### Аккаунт и социальные функции
- ✅ Регистрация по @username + пароль, вход, **2FA PIN** (4–6 цифр)
- ✅ **Вход через Google** и **вход через Telegram** — кнопки с оригинальными
  иконками на экране приветствия; аккаунт привязывается к почте/Telegram,
  повторный вход в один клик
- ✅ Уведомление в TeleMAX Bot при входе с нового устройства (устройство, IP, код)
- ✅ Профиль: аватар (обновляется сразу, без выхода из профиля), имя, «о себе»,
  телефон, статистика (медиа/файлы/голосовые/группы), подарки
- ✅ **Диагностика мессенджера** (Настройки → «Диагностика мессенджера»):
  живой онлайн — сколько людей сидит сейчас, всего зарегистрировано, новых за
  сегодня, очередь сообщений, аптайм сервера, пинг, ваше время в приложении.
  Живой счётчик «N онлайн • всего M» виден и на стартовом экране входа
- ✅ **Вход с любого устройства** (телефон, планшет, ПК, консоль): при входе
  история чатов подгружается с сервера автоматически, без дублей; удалённые
  сообщения не возвращаются
- ✅ **Экспорт и импорт чатов (JSON)** (Настройки → «Данные и память»):
  экспорт сохраняет историю в файл, импорт вливает файл обратно на любом
  устройстве (дубликаты пропускаются)
- ✅ Контакты: список всех пользователей, онлайн-точки, поиск
- ✅ **TeleCoin**: баланс (старт 1250 TC), переводы, пополнение, история
- ✅ **Подарки и NFT** — каталог с ценами (50–1000 TC), NFT-инвентарь,
  **TelePremium за 499 TC** (подарок на 30 дней)
- ✅ **Облачное хранилище** — личный канал `clstXXXX`, загрузка/скачивание файлов
- ✅ 10 фонов чата, акцентные цвета, анимации
- ✅ Магазин **200 плагинов** (поиск, категории, установка/включение)
- ✅ Для разработчиков: Debug Mode, логирование, проверка соединения,
  адрес сервера, сброс настроек
- ✅ Языки: Русский / English / Español (переключение в настройках)

### 🛡 Admin Mode (роли 0–5)
Секретный вход: **Настройки → «О TeleMAX» — нажать 7 раз** → ввести код
(по умолчанию `testtestest654`, меняется переменной `TMX_ADMIN_KEY` на сервере).
Встроенные аккаунты уровня 5: `mislit_tech`, `i_11_bot` — просто
зарегистрируйте @mislit_tech обычным способом, он автоматически получит
уровень 5, верификацию и доступ к админ-панели без кода (7 тапов на «О TeleMAX»).

Роли: `0` заблокирован • `1` пользователь • `2` младший модератор •
`3` старший модератор • `4` администратор • `5` спецверификатор.

**Уровень 4+ (всё из Android-версии):**
- 📊 Аналитика онлайна — **кто сейчас сидит и сколько времени**, счётчики:
  всего аккаунтов, онлайн, **новых за сегодня**, баны, заморозки, муты,
  верификации, Premium, админы, группы, очередь, сокеты, аптайм
- 👥 Аккаунты (поиск, детали, устройства), роли 0–5, верификация
  (только при **точном** совпадении имени и @username), проверка верификаций
- 🔒 Ban / Unban / Freeze / Unfreeze (сброс роли в 0, как в приложении)
- 🆕 Карточка аккаунта: **выдать/отключить TelePremium**, **сбросить 2FA PIN**,
  **сменить имя**, **завершить все сессии** (кик со всех устройств)
- ⚠️ Жалобы (проверка и применение), модерация: предупреждение / мут / кик
- 💰 Выдача TeleCoin, выдача NFT, **клинок подарков** (удаление всех или выбранных)
- 📢 Системная рассылка всем (приходит и в TeleMAX Bot-чат)
- 🔑 Сессии и **служебный вход** (одноразовый код владельца на 10 минут → уровень 4)
- 🧩 Плагины, ⚙ Сервис (диагностика, /health, очистка очереди), безопасность

**Уровень 3:** создание жалоб, согласование для администратора, статистика чатов,
поиск сообщений, просмотр онлайна, история действий, уведомления, временный бан,

## ⚙️ Сервер

- Отдаёт сайт и работает как WebSocket-хаб на одном порту: **8080**
- Сохраняет данные в `server/telemax-state.json`
- Файлы складывает в `server/uploads/` (до 500 МБ на файл)
- `/health` — проверка состояния (версия, онлайн, аккаунты, аптайм)
- Порог и ключ админа меняются: `PORT`, `TMX_ADMIN_KEY`; путь к файлу данных —
  `TMX_STATE` (удобно для тестовых запусков)

### Тест сервера

```bash
cd server
npm test          # node smoke-test.js (нужен запущенный сервер на порту 8099
                  #  через:  $env:PORT=8099; node index.js )
```

## 🌍 Ссылка для всех (публичный доступ)

1. Запустите сервер: `telemax start` (или `npm start`).
2. В отдельном окне: `telemax tunnel` (или `npm run tunnel`) — появится ссылка
   вида `https://xxxx.lhr.life` (публичный URL).
3. Отправьте ссылку кому угодно — сайт открывается через интернет, по HTTPS.

- Публичный доступ живёт, пока открыто окно с туннелем (`telemax tunnel` /
  `TUNNEL.bat`). Закрыли окно — доступ выключен.
- Каждый запуск туннеля выдаёт новую ссылку (бесплатный сервис без регистрации).
- Сайт доступен по HTTPS — значит, микрофон, камера и звонки у гостей тоже работают.
- Туннель использует встроенный в Windows `ssh` (ничего скачивать не нужно).
  Ручной запуск без скрипта: `ssh -R 80:127.0.0.1:8080 nokey@localhost.run`
- Запасной вариант — cloudflared (`tools\cloudflared.exe`), но у некоторых провайдеров
  соединение с Cloudflare блокируется; SSH-туннель надёжнее.

## 🔔 Важно

- Для интернета (не только localhost) используйте туннель (`telemax tunnel`,
  `npm run tunnel` или `TUNNEL.bat`) — он даёт HTTPS-ссылку;
  браузеры не дают микрофон/камеру на несекюрных адресах кроме localhost.
- Сервер поддерживает `resume`-токены: после перезагрузки страница входит сама.
- «Прокси» в настройках — для загрузок через сервер; звонки идут напрямую (WebRTC/STUN).
