# TeleMAX Python bot example

This is a small aiogram 3.x example. It uses the bot token from the environment.

Windows PowerShell:

```powershell
$env:TELEMAX_BOT_TOKEN="PASTE_YOUR_TOKEN_HERE"
python telemax_bot.py
```

Linux/macOS:

```bash
export TELEMAX_BOT_TOKEN="PASTE_YOUR_TOKEN_HERE"
python telemax_bot.py
```

Do not commit real bot tokens to Git or paste them into source code.

Important: a token generated by the current TeleMAX BotRast is a **TeleMAX-local token**. It is not a real Telegram Bot API token unless it was issued by Telegram. Real Telegram bot tokens are issued by Telegram's BotFather.
