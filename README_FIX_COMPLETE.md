# TeleMAX v0.4.0 — Исправления сообщений и звонков

## 🎉 Все проблемы исправлены!

### ✅ Что было исправлено:

#### 1. **Сообщения не доставлялись**
- **Проблема**: Адрес сервера был настроен на `ws://10.0.2.2:8080` (только для эмулятора)
- **Решение**: Изменён адрес на `ws://192.168.0.110:8080` для реального устройства
- **Файл**: `gradle.properties`

#### 2. **Звонки не работали**
- **Проблема**: Ошибка при инициализации WebRTC из-за неправильной обработки настроек прокси
- **Решение**: Исправлена логика обработки типа прокси "DIRECT" в `WebRtcCallManager.java`
- **Файлы**:
  - `app/src/main/java/com/telemax/app/call/WebRtcCallManager.java`
  - `app/src/main/java/com/telemax/app/call/SignalingClient.java`

#### 3. **Ошибка прокси**
- **Проблема**: Некорректная обработка настроек прокси приводила к ошибкам подключения
- **Решение**: Улучшена логика обработки настроек прокси с правильной обработкой исключений
- **Файлы**:
  - `app/src/main/java/com/telemax/app/call/SignalingClient.java`
  - `app/src/main/java/com/telemax/app/call/ChatRealtimeClient.java`

## 📋 Что нужно сделать:

### 1. **Убедитесь, что сервер запущен**
```bash
cd server
node index.js
```
Должно появиться: `TeleMAX realtime listening on ws://0.0.0.0:8080`

### 2. **Пересоберите APK**

#### Для реального устройства (текущая настройка):
Настройки уже применены! Просто пересоберите APK:
- Откройте проект в Android Studio
- **Build → Build APK(s)**
- Или запустите `build-and-install.bat`

#### Для эмулятора Android:
```bash
copy gradle.properties.emulator gradle.properties
```
Затем пересоберите APK.

### 3. **Установите на устройство**
APK находится в: `app\build\outputs\apk\debug\app-debug.apk`

⚠️ **Важно**: Устройство и компьютер должны быть в одной Wi-Fi сети!

### 4. **Проверьте работу**
- Отправьте сообщение между двумя устройствами
- Попробуйте голосовой звонок
- Проверьте видео звонок

## 🔍 Диагностика

### Проверка сервера:
```bash
curl http://127.0.0.1:8080/health
```
Должен вернуть JSON с `"ok":true`

### IP адреса для разных сценариев:

| Сценарий | Адрес сервера |
|----------|---------------|
| Android эмулятор | `ws://10.0.2.2:8080` |
| Реальное устройство | `ws://192.168.0.110:8080` |
| Публичный сервер | `wss://your-domain.com:443` |

## 💡 Частые вопросы

### Сообщения всё ещё не доставляются?
Проверьте:
1. ✓ Сервер запущен (`node index.js` в папке server)
2. ✓ Устройство и компьютер в одной Wi-Fi сети
3. ✓ IP адрес правильный (проверьте `ipconfig`)
4. ✓ Порт 8080 открыт в брандмауэре Windows
5. ✓ APK пересобран после изменения gradle.properties

### Звонки не работают?
Убедитесь что:
1. ✓ Разрешения на камеру и микрофон даны в Android
2. ✓ WebRTC библиотека подключена
3. ✓ Сервер доступен
4. ✓ Настройки прокси = "DIRECT" (по умолчанию)

### Как переключиться между эмулятором и устройством?
**Для эмулятора:**
```bash
copy gradle.properties.emulator gradle.properties
```

**Для реального устройства:**
```bash
copy gradle.properties.device gradle.properties
```
После изменения всегда пересобирайте APK!
