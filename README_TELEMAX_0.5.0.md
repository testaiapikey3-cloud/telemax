# TeleMAX v0.5.1

Обновлённый Android-проект TeleMAX.

## Что изменено
- MAX-inspired тёмный интерфейс с жёлтым акцентом и нижней навигацией.
- Экран приветствия → регистрация/вход.
- Telegram-style PIN/2FA сохранён.
- Обновлены настройки: Digital ID, уведомления, облако, прокси, приватность, звонки, TeleCoin/Premium, NFT и Developer Mode.
- Добавлен Debug Mode и диагностика.
- Добавлено личное облачное хранилище с каналом `clst` + 5 случайных цифр.
- Добавлена локальная галерея NFT/подарков.
- Добавлены плавные анимации появления экранов.
- Экран звонка визуально переработан под современный MAX-style.

## Важное
- Sfera/«Сферум» удалён из интерфейса.
- Для Google-входа ошибка 10 означает отсутствие корректного Android OAuth client/SHA-1 для `com.telemax.app`; это настраивается в Google Cloud, а не исправляется Java-кодом.
- Файлы/медиа отправляются через HTTP upload endpoint `/upload`, который предоставляет сервер TeleMAX. WebRTC-сигналинг теперь не показывает ошибочные всплывающие сообщения при недоступном сервере.

## Сборка
Открой корневую папку проекта в Android Studio и выполни обычный Gradle Sync/Build.

Важно: realtime и WebRTC требуют настроенного сервера/Signaling/TURN; UI и локальные функции работают независимо от их доступности.
